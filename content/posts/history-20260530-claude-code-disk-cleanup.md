# 还要啥清理软件呀，Claude Code 帮我清理了 100G 磁盘

自从搞AI以后，电脑的磁盘越来越不够用了，有时候整个电脑卡死了，才意识到电脑磁盘告急了，就不得不用清理磁盘工具清理一波，比如CleanMyMac、mole等。今天想将这个活丢给 Claude Code：“用 workflow 帮我做个磁盘体检，看看哪些可以清理、哪些是必要的，给我做一份体检报告。”

接下来它没急着删东西，而是先把全盘扫了一遍、列出报告，再分几轮停下来等我拍板，确认一批清一批。等这一圈走完，可用空间从 97G 涨到 **178G**——清出 81G，占用率从 78% 压到 60%。

但这篇不想报「清了哪些东西」的流水账。真正值得说的是它**怎么干这件事**，以及**我在中间到底做了什么**。

## 一、它的思路：先体检，再动手

第一步是**体检**——一次并行派出 6 个 agent，分头去摸家目录的不同区域：系统库、各种缓存、工具目录、代码工作区、容器虚拟机、下载和废纸篓。

跟我上一篇聊的[动态 workflow](https://mp.weixin.qq.com/s/nNKgkKxETGDGTR4vyoiqAA)是同一套路子：把一件大事拆开，让多个 agent 同时干，再把结果汇到一起。

![并行 6 个 agent 分区体检磁盘](https://raw.githubusercontent.com/liuhedev/liuhedev.github.io/main/public/images/articles/20260530-claude-code-disk-cleanup/8f29aab3d42e106eb7e425f5e3e1cb825f030fe4d105a56d7813e8ae4e3ef70f.jpg)

关键在于，每个 agent 不只是报个大小，而是把每一项都判成三类：

- **能安全删**：删了会自动重建的缓存、构建产物；
- **要你确认**：聊天记录、虚拟机镜像这种删了有损失的；
- **必须留**：源码、笔记、凭证。

体检完它先给我一份报告，告诉我哪些能闭眼清、哪些得我点头。**先想清楚再下手，这一步就比扫描器靠谱。**

![体检报告：每项分成能删 / 要确认 / 必须留](https://raw.githubusercontent.com/liuhedev/liuhedev.github.io/main/public/images/articles/20260530-claude-code-disk-cleanup/346a91133a33d16106397a032954ea95403f0628be712f91c5826ecd9f46767d.jpg)

另外，这套体检逻辑它还顺手存成了一个可复用的 `/disk-health-check`，核心就几行——并行派出去，每个区域按同一套规则分类：

![disk-health-check 工作流脚本](https://raw.githubusercontent.com/liuhedev/liuhedev.github.io/main/public/images/articles/20260530-claude-code-disk-cleanup/b9cdccb7cce9f7edcc2da8fdf42ca20208493c1c5fd43abbe8c736ad729957af.jpg)

下次再想体检，一句 `/disk-health-check` 就能重新跑一遍。

## 二、我在中间只做了几个决定

整个过程我几乎没动手，只在它停下来问我的时候，拍几个板：

它发现我机器上同时装了三套做同一件事的容器工具：OrbStack、Docker Desktop、Colima，纯属冗余，问我留哪个——我说留 Colima，它就把另外两套的数据删了，还顺手把失效的 docker 配置（context）一起清了。

碰到几个我早就不用的 AI 编程工具——比如通义灵码、Antigravity，它问要不要卸——我说卸，它连数据带缓存一起收掉，但很有分寸：只删这两个工具自己的目录，没碰我还在用的同系列配置。

最有意思的是一个膨胀的git仓库。它先试了温和的办法，发现没用，就**直接告诉我实话**：要真瘦下来得动「重写历史」这种高风险操作。然后它没擅自动手，而是停下来说——「要做可以，但我得先给你做完整备份」，甚至提醒我有些东西还没同步到云端，光靠云端不算安全备份。

> 这种「危险的事先停下来、先兜底」的分寸感，是我最想强调的一点。

所以我的角色，从头到尾就是**定方向、做选择**。脏活累活、判断哪个能删哪个不能删、删之前查有没有进程在占用、边删边算回收了多少——全是它在干。

## 三、为什么这比清理软件强

传统清理软件的逻辑是「按固定规则扫已知的缓存目录」。它不认识的目录就跳过，更不会判断「这个该不该删」。

Claude Code 的不一样，在于它**真的读得懂**：每个目录是干嘛的、能不能删、删了有什么后果，它会去看、去想、去问。该自动的自动，该停的停。

```bash
# 清理前 → 清理后
可用 97G（78% 满）  →  可用 178G（60%）
```

这更像是请了一个懂行的工程师帮你做磁盘体检，而不是塞给你一个无脑扫描器。我定方向，它动手，碰到危险的地方还会先拦我一下。这套配合下来，我的清理软件确实可以卸了。
